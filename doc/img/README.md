# Sobre esta carpeta:

### `doc/img/`

Situa nesta carpeta todas as imaxes ás que faga referencia a documentación.

**IMPORTANTE**: Procura utilizar `PNG` como formato de imaxe e que estas non ocupen demasiado espacio.

`logo.png` e `logo-oscuro.png` son o icono actual da app, a pastilla semirrellena
de `PillRemind/app/src/main/res/drawable/ic_launcher_foreground.xml`,
renderizada sobre fondo transparente: violeta de marca no tema claro e violeta
claro no tema escuro de GitHub. Se cambia o icono, hai que rexenerar os dous.
