# Sobre esta carpeta:

### `doc/img/`

`logo.png` e `logo-oscuro.png` son o icono actual da app
(`ic_launcher_foreground.xml`) sobre fondo transparente: azul profundo
(`#15325E`) no tema claro e azul cielo (`#A9C8FF`) no escuro. Se cambia o
icono ou a paleta, hai que rexenerar os dous PNG en sRGB.
